tagline: Run untrusted AI-agent code in isolated microVMs you host yourself, inside your own network.
description: 'An open-source runtime for running AI-agent code in isolated microVMs that you host yourself. Hosted sandboxes like E2B and Modal run your code in their cloud. emberd runs it on your own machine, inside your own network. You create a sandbox, it boots a real Firecracker microVM, runs your code inside it, returns the output, then destroys it. The base image is read-only, each sandbox gets a throwaway writable layer, and a sandbox runs with no network device by default.'
